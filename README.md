# spice_lane_eats

Restaurant ordering app for Spice Lane with menu browsing, cart, Stripe checkout, pickup/delivery, order history, and staff menu management

## Tech Stack

- **Backend:** Express.js + TypeScript + Prisma ORM
- **Frontend:** React + TypeScript + Vite
- **Database:** PostgreSQL, with the Prisma migration history in backend/prisma/migrations
- **Auth:** JWT (JSON Web Tokens)

## Run it locally

You need Node 20 or newer, and Docker (or a PostgreSQL of your own).

```bash
# 1. The database from docker-compose.yml, on localhost:5432
docker compose up -d db

# 2. Backend
cd backend
npm install
cat > .env <<'ENV'
DATABASE_URL=postgresql://app:app@localhost:5432/app
SEED_DEMO_PASSWORD=choose-a-demo-password
ENV
npx prisma migrate deploy
npm run seed
npm run dev

# 3. Frontend, in a second terminal
cd frontend
npm install
npm run dev
```

`npm run seed` creates the demo and staff accounts and the sample data, with SEED_DEMO_PASSWORD as their password
(Shikshya's Env tab shows the one this project was generated with); without it the seed adds nothing. The backend
answers on http://localhost:8000 and Vite prints the frontend's address.

## Deploy on Railway

1. In Railway, create a project from this GitHub repository.
2. Add a PostgreSQL database to the project (Railway's Postgres template). Railway names the service `Postgres`.
3. In your app service's **Variables**, set:
   - `DATABASE_URL` = `${{Postgres.DATABASE_URL}}` (Railway fills in the database's address)
   - `JWT_SECRET` = a long random string
   - `NODE_ENV` = `production`
   - `SERVE_FRONTEND` = `1` (the backend serves the built frontend)
   - leave `SEED_DEMO` unset: a production database gets no demo accounts
   - `STRIPE_SECRET_KEY` and `STRIPE_WEBHOOK_SECRET` = from your Stripe dashboard (without them the payment routes answer 503)
4. Deploy. Railway sets `PORT` itself.

## Docker

```bash
docker compose up --build
```

The app applies the migrations when it starts. Set POSTGRES_PORT or APP_PORT when 5432 or 8000 is taken.
